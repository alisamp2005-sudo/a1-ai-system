# Telegram Bot (Пользовательский интерфейс)

Бот написан на Python с использованием фреймворка `aiogram 3.x`. Он является единственным окном входа для большинства сотрудников.

## Основные команды

| Команда | Доступ | Описание |
|---------|--------|----------|
| `/start` | Все | Приветствие, запрос номера телефона для авторизации. |
| `/help` | Все | Справка по работе с ботом, примеры запросов. |
| `/report` | Прорабы, РП | Открывает Web App (Mini App) для сдачи ежедневного отчета. |
| `/tasks` | Все | Список активных задач пользователя. |
| `/status` | ГД, Зам | Сводка по всем объектам (вызов Агента-Сводчика). |

## Обработка типов сообщений

1. **Текст:** Передается напрямую в Router (LangGraph).
2. **Голосовое сообщение (Voice):** 
   - Скачивается локально (`.ogg`).
   - Отправляется в модель Whisper Large v3.
   - Полученный текст передается в Router.
3. **Фото (Photo):**
   - Скачивается локально.
   - Если сопровождается текстом "проверь ТБ", маршрутизируется Агенту Безопасности (LLaVA).
   - Если это часть отчета прораба, прикрепляется к отчету в БД.
4. **Документ (Document):**
   - PDF/Excel скачиваются.
   - Передаются профильному агенту (Юристу или Финансисту).

## Inline-кнопки (Согласование)

Для задач, требующих решения ГД (Алимова З.Т.), бот отправляет сообщение с Inline-клавиатурой:
- 🟢 Согласовать
- 🔴 Отклонить
- 🟡 Уточнить (вызывает диалог с агентом/инициатором)
- 🔵 Делегировать (выбор кому передать)
- ⚪ Отложить (задача ставится на паузу)

## Telegram Mini Apps

Для сложных форм (отчет прораба, заявка на ТМЦ) используются Mini Apps — веб-страницы, открывающиеся внутри Telegram. 
Это позволяет использовать выпадающие списки, чекбоксы, мульти-загрузку фото, что невозможно сделать удобным через обычный чат.
