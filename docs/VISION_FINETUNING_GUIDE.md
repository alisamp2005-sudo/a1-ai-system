## 2. Сколько фото нужно для обучения

### Минимальный набор (для начала):
- **200-300 фото** — уже даст заметное улучшение
- По 10-15 фото на каждую категорию нарушений (A-F)
- 50-100 фото БЕЗ нарушений (чтобы модель не выдумывала)

### Оптимальный набор:
- **500-1000 фото** — хорошее качество распознавания
- По 30-50 фото на каждую категорию
- 200+ фото без нарушений

### Идеальный набор:
- **2000-5000 фото** — production-качество
- По 100+ фото на каждую категорию
- Разные условия: день/ночь, дождь/солнце, разные объекты

### Требования к фото:
- Разрешение: минимум 640x480, лучше 1280x720+
- Формат: JPEG или PNG
- Ракурсы: разные (общий план, средний, крупный)
- Условия: разное освещение, погода
- Объекты: разные стройплощадки (не только одна)

## 3. Формат датасета для обучения

Каждый пример — JSON с изображением и описанием:

```jsonl
{"image": "photos/001.jpg", "conversations": [{"role": "user", "content": "<image>\nAnalyze this construction site photo for safety violations."}, {"role": "assistant", "content": "SEVERITY: HIGH\n\nVIOLATIONS:\n- Worker on scaffolding without hard hat (HIGH)\n- Missing guardrail on second level (HIGH)\n\nRECOMMENDATIONS:\n- Immediately provide hard hats to all workers\n- Install guardrails on all open edges above 1.8m"}]}
{"image": "photos/002.jpg", "conversations": [{"role": "user", "content": "<image>\nAnalyze this construction site photo for safety violations."}, {"role": "assistant", "content": "SEVERITY: NONE\n\nNo safety violations detected. All workers are wearing proper PPE (hard hats, safety vests). Guardrails are in place. Site is clean and organized."}]}
```

Файлы:
- `train.jsonl` — 80% данных (обучение)
- `valid.jsonl` — 10% данных (валидация)
- `test.jsonl` — 10% данных (тест)

## 4. Как обучить (Fine-tuning на Mac M4 Pro 64GB)

### Шаг 1: Установка инструментов

```bash
pip3 install mlx-vlm mlx-lm
# или
pip3 install mlx-tune
```

### Шаг 2: Подготовка датасета

Структура папки:
```
dataset/
├── train.jsonl
├── valid.jsonl
├── test.jsonl
└── photos/
    ├── 001.jpg
    ├── 002.jpg
    └── ...
```

### Шаг 3: Запуск обучения (LoRA fine-tuning)

```bash
python3 -m mlx_vlm.lora \
    --model mlx-community/Llama-3.2-11B-Vision-Instruct-8bit \
    --data ./dataset \
    --train \
    --batch-size 1 \
    --lora-layers 8 \
    --epochs 3 \
    --learning-rate 1e-5 \
    --adapter-path ./adapters/safety-v1
```

Параметры:
- `--batch-size 1` — для 64 ГБ RAM (можно попробовать 2)
- `--lora-layers 8` — количество слоёв LoRA (больше = точнее, но медленнее)
- `--epochs 3` — количество проходов по датасету
- `--learning-rate 1e-5` — скорость обучения (стандарт для LoRA)

### Шаг 4: Время обучения (оценка)

| Количество фото | Время на M4 Pro 64GB |
|---|---|
| 200 фото | ~1-2 часа |
| 500 фото | ~3-5 часов |
| 1000 фото | ~8-12 часов |
| 2000 фото | ~20-24 часа |

### Шаг 5: Тестирование обученной модели

```bash
python3 -m mlx_vlm.generate \
    --model mlx-community/Llama-3.2-11B-Vision-Instruct-8bit \
    --adapter-path ./adapters/safety-v1 \
    --image test_photo.jpg \
    --prompt "Analyze this construction site photo for safety violations."
```

### Шаг 6: Интеграция в систему

После обучения обновить `scripts/vision_service.py`:
```python
# Добавить загрузку адаптера
model, processor = load(
    "mlx-community/Llama-3.2-11B-Vision-Instruct-8bit",
    adapter_path="./adapters/safety-v1"
)
```

## 5. Как собирать фото для датасета

### Что фотографировать:

**Нарушения (POSITIVE):**
1. Рабочие без касок (разные ракурсы)
2. Рабочие без жилетов
3. Открытые проёмы без ограждений
4. Захламлённые проходы
5. Повреждённые леса
6. Работа на высоте без страховки
7. Открытые электрощиты
8. Неправильное складирование

**Норма (NEGATIVE — очень важно!):**
1. Все в касках и жилетах
2. Чистая площадка
3. Правильные ограждения
4. Исправные леса
5. Порядок на площадке

### Правила фотографирования:
- Снимать с расстояния 3-10 метров (как инспектор)
- Включать в кадр контекст (не только лицо, а всю ситуацию)
- Фотографировать при разном освещении
- НЕ постановочные фото — реальные рабочие ситуации

## 6. Альтернативный подход: YOLO + классификация

Если Vision LLM не даёт нужной точности, можно использовать **YOLO** (специализированная модель детекции объектов):

1. **YOLOv8/YOLO26** — детектирует каски, жилеты, людей
2. Готовые датасеты: [Construction-PPE Dataset](https://docs.ultralytics.com/datasets/detect/construction-ppe) (1416 фото, 11 классов)
3. Обучение: 30-60 минут на Mac M4 Pro
4. Точность: 90%+ после обучения на 500+ фото

Этот подход проще и надёжнее для конкретной задачи "есть каска / нет каски".

```bash
pip3 install ultralytics
yolo detect train model=yolo11n.pt data=construction-ppe.yaml epochs=50
```

**Рекомендация:** Использовать YOLO для детекции СИЗ (каски, жилеты) + Vision LLM для общего анализа ситуации. Комбинированный подход даст лучший результат.

## 7. План действий

1. **Сейчас:** Собирать фото с объектов (минимум 200-300)
2. **Разметка:** Для каждого фото написать что на нём (нарушения или норма)
3. **Обучение:** Запустить fine-tuning (1-2 часа на 200 фото)
4. **Тест:** Проверить на новых фото
5. **Итерация:** Добавлять фото где модель ошибается, переобучать

Весь процесс можно начать с 50 фото для proof-of-concept, потом наращивать.
